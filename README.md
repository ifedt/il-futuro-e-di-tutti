# Il Futuro è di Tutti

Sito statico dell'associazione, predisposto per GitHub Pages.

## Pubblicazione

1. Crea su GitHub il repository pubblico `il-futuro-e-di-tutti` nell'account `ifedt`.
2. Carica il contenuto di questa cartella nella radice del repository.
3. In **Settings → Pages**, seleziona **Deploy from a branch**, branch `main`, cartella `/(root)`, quindi **Save**.
4. Il sito sarà disponibile a `https://ifedt.github.io/il-futuro-e-di-tutti/`.

Per usare il dominio `ilfuturoeditutti.it`, aggiungi in seguito il file `CNAME` con tale dominio e configura i DNS secondo le istruzioni mostrate da GitHub Pages.
